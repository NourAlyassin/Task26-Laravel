# Simple Laravel Blog — Routes & Views

A minimal Laravel blog built using the **Revolve Blog Template**. This project
demonstrates the fundamentals of Laravel routing, controllers, and Blade views
while keeping a clean, organized folder structure.

---

## 📋 Overview

The application displays three core pages — **Home**, **About**, and **Contact** —
each served through its own route and controller, and rendered with Blade templates
built on top of the Revolve Blog Template. A shared navigation menu links all pages
together, and the template's CSS, JS, and image assets are wired in properly.

---

## ✨ Features

- Laravel project initialized from scratch
- Routes for the main pages: **Home**, **About**, **Contact**
- Dedicated controllers for each page
- Blade templating with a shared layout
- Navigation menu linking all pages
- Template assets (CSS, JS, images) integrated via 
- Organized, convention-based folder structure

---

## 🛠️ Tech Stack

| Technology   | Purpose                          |
|--------------|----------------------------------|
| PHP          | Backend language                 |
| Laravel      | MVC framework                    |
| Blade        | Templating engine                |
| Revolve Blog | Frontend HTML/CSS/JS template    |
| Bootstrap    | Styling (as provided by template)
